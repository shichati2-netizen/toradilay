# בניית תורה דיליה ל-Windows

הבנייה האוטומטית מופעלת אחרי push לענף כלשהו או ידנית דרך GitHub Actions → Build ToraDelia for Windows.

## קובץ ההורדה

תהליך הבנייה מפרסם **קובץ ZIP יחיד**: `ToraDelia-Kiosk-Windows.zip`.
בתוך ה-ZIP נמצא קובץ אחד בלבד: `ToraDelia-Kiosk.exe` — גרסת Portable.

## הפעלה ללא התקנת מסד נתונים

האפליקציה אינה דורשת PostgreSQL, שרת חיצוני, כתובת `DATABASE_URL` או יצירה ידנית של `app.env`.
ההגדרות ויומן הפעילות נשמרים מקומית בתיקיית הנתונים של משתמש Windows, מחוץ לתיקיית ההתקנה, ולכן נשמרים גם לאחר החלפת גרסה.

## Google Drive ורישום

בחיבור ראשוני ל-Google Drive, יש להשלים את ההתחברות מתוך ממשק הניהול של האפליקציה. רישום ל-Google Sheets דורש חיבור והרשאות Google תקינים. קובץ `app.env` עדיין נקרא אם קיים, לצורך משתני סביבה מתקדמים בלבד; הוא אינו נחוץ להפעלה רגילה.
